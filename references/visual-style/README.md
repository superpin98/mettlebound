# Referencias visuales para Mettlebound

Estas capturas provienen del kit "Grimspire" (un mockup completo de juego pixel-art 2D) y se usan como **referencia de estilo** para la UI del juego Mettlebound. Mettlebound NO es pixel art: es 3D low poly con una capa de UI 2D estilizada al estilo de juegos como Hades, Slay the Spire o Darkest Dungeon.

## Qué tomar prestado del kit

- ✅ Tipografía blackletter dorada para títulos
- ✅ Tipografía pixel/monospace para estado/números
- ✅ Paneles con borde dorado fino sobre fondo morado oscuro
- ✅ Sistema de color por rareza (morado mítico, azul raro, rojo maldito, verde, amarillo)
- ✅ Tarjetas tipo "boon" con icono grande, título, stats y flavor text
- ✅ Iconografía minimalista geométrica
- ✅ Estética dark fantasy general

## Qué NO usar del kit

- ❌ Pixel art puro para personajes, enemigos o entornos (Mettlebound es 3D)
- ❌ Filtros CRT / scanlines / pixel scale (no van con 3D)
- ❌ Spritesheets animados

## Uso de este material

Este es **material de inspiración**, no assets a usar literalmente. Cuando llegue el sprint de "UI Pass", el diseño final de Mettlebound se inspirará en estas referencias pero adaptándose al contexto 3D low poly del juego y a las decisiones estéticas propias.
