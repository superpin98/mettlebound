# Assets de Mettlebound

Todos los assets 3D de este directorio son **CC0** (uso libre, sin atribución requerida) de **Kay Lousberg**.

## Origen

- **Personajes** (assets/models/characters/): KayKit Character Pack - Adventurers 1.0
  https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
  Modelos: Barbarian, Knight, Mage, Rogue, Rogue_Hooded

- **Dungeon** (assets/models/dungeon/): KayKit Dungeon Pack Remastered 1.0
  https://github.com/KayKit-Game-Assets/KayKit-Dungeon-Remastered-1.0
  Contenido: paredes modulares, suelos, decoracion, mobiliario, escaleras

- **Texturas** (assets/textures/): Atlas de textura compartido para todos los modelos
